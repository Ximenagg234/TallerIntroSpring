# Taller 1 - Sistema de Gestión de Discografía

Proyecto desarrollado con Spring Framework y Servlets.

## Versiones

- version-xml → Configuración usando XML
- version-annotations → Configuración usando anotaciones
- version-javaconfig → Configuración usando @Bean y Java Config

## Tecnologías
- Java 21
- Maven
- Spring Context
- Spring Web
- Tomcat
- Bootstrap

## Funcionalidades
- CRUD completo de Artistas
- CRUD completo de Tracks
- Relación Many-to-Many
- Inicialización automática de datos
